# Baseline Results

This directory contains the experimental outcomes of the traditional machine learning baselines established in TASK 007.

## Files
- `baseline_results.csv`: A cumulative log of all baseline experiments run, including their IDs, parameters, and high-level metrics.
- `[experiment_id].json`: The detailed artifact containing the precise configuration, dataset metadata, seed, leakage checks, split sizes, and granular metrics (per-class F1, exact match ratios, etc.) for a specific run.

## Note on Results
All numbers located in this directory are **PROJECT EXPERIMENTAL RESULTS** derived directly from executed code on local datasets. 
They do NOT represent published literature results.
